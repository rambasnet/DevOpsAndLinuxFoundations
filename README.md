- provides Jupyter notebooks and exercises to help learners understand the fundamentals of DevOps and cloud computing, with a focus on Linux-based systems
- provide labs in a hands-on manner to help learners gain practical experience with Bash scripting, Git, CI/CD pipelines, and Docker containers

## Linux Fundamentals

- provides a brief overview of Linux fundamentals, including basic commands, file system navigation, and essential concepts for working with Linux-based systems

## Bash Scripting

- covers the basics of Bash scripting, including variables, loops, conditionals, and functions, enabling users to automate tasks and create simple scripts for system administration

## Git and Version Control

- introduces Git, a widely used version control system, and covers best practices for managing code repositories, branching, merging, and collaborating with others

## CI/CD Pipelines

- explains the concepts of Continuous Integration and Continuous Deployment (CI/CD), and provides guidance on setting up automated pipelines for building, testing, and deploying applications
- shows how to integrate CI/CD tools and services to streamline the software development lifecycle and improve code quality and security

## Docker and Containers

- provides an introduction to Docker, a popular containerization platform, and covers the basics of creating, managing, and deploying containers for application development and deployment
